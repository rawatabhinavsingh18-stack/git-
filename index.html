📄 About the Paper

DeepDTA: Deep Drug–Target Binding Affinity Prediction

AuthorsHakime Öztürk, Arzucan Özgür, Elif Ozkirimli
JournalBioinformatics, Vol. 34, 2018, pp. i821–i829
DOI10.1093/bioinformatics/bty593
Codegithub.com/hkmztrk/DeepDTA
ConferenceECCB 2018

Drug-Target Interaction (DTI) prediction is a cornerstone of drug discovery. Traditional methods predict binary interactions (binds / does not bind). DeepDTA advances this by predicting the continuous binding affinity score — a regression problem — giving far more nuanced and actionable information for drug discovery pipelines.

Prior methods like KronRLS and SimBoost relied on handcrafted feature engineering (2D similarity matrices via PubChem Sim, Smith–Waterman alignment) which is computationally expensive and loses raw structural information. DeepDTA bypasses all external feature extraction by learning directly from raw 1D sequences.

  • Input: Only 1D sequences — SMILES strings for drugs, amino acid sequences for proteins
  • No 3D structures needed — overcomes the PDB limitation (~25,000 ligands)
  • No external features — no Smith–Waterman, no PubChem similarity matrices
  • Two parallel CNN blocks learn representations independently for drugs and proteins
  • Label encoding: characters mapped to integers (e.g. C→1, H→2, N→3); embedded into 128-dim vectors
  • Representations are concatenated and passed to fully connected layers (DeepDTA block)
DatasetProteinsCompoundsInteractionsAffinity Measure
Davis4426830,056pKd (−log₁₀(Kd/10⁻⁹))
KIBA2292,111118,254KIBA score (Ki + Kd + IC₅₀)

SMILES strings were obtained from PubChem using compound CIDs. Protein sequences from UniProt.

  • Drug CNN Block: 3 × 1D-Conv layers (32 → 64 → 96 filters) + MaxPooling
  • Protein CNN Block: Same structure (32 → 64 → 96 filters) + MaxPooling
  • Both outputs concatenated → 3 Fully Connected layers: 1024 → 1024 → 512 → output
  • Dropout 0.1 after first two FC layers
  • Activation: ReLU | Optimizer: Adam (lr=0.001) | Loss: MSE | Epochs: 100 | Batch: 256

DeepDTA (CNN+CNN) achieves the best Concordance Index on KIBA (0.863, p < 0.0001 vs both baselines) and competitive performance on Davis (0.878). It also achieves the lowest MSE on both datasets.

Key finding: CNN blocks learning from raw SMILES is more powerful than predefined PubChem similarity. CNN for proteins alone underperforms, but combined with drug CNN, results improve substantially.

  • Explore LSTM/RNN for protein sequences (better at long-range dependencies)
  • Ligand-based protein representation using interacting SMILES
  • Extend to novel drug–target pairs beyond training distribution
  • Protein deorphanization — predicting interactions for currently untargeted proteins

🧮 Encoding Scheme

Characters in SMILES/protein sequences are mapped to unique integers (label encoding), then embedded into 128-dimensional vectors via a Keras Embedding layer. Shorter sequences are zero-padded; longer ones are truncated.

SMILES: "CN=C=O" → [13, 6, 3, 16, 3, 5] Protein: "MKK..." → [12, 10, 10, ...]

⚙️ Training Setup

  • Loss: Mean Squared Error (MSE)
  • Optimizer: Adam (lr = 0.001)
  • Epochs: 100 | Batch size: 256
  • Activation: ReLU throughout
  • Regularization: Dropout (0.1)
  • Framework: Keras + TensorFlow backend
  • Hardware: GeForce GTX 1070 (8GB) + cuDNN

📐 Hyperparameter Search

Grid search over filter sizes [4,6,8] for drugs and [4,8,12] for proteins, and filter counts from [16,32,64,128,512]. Best config: 32 base filters (resulting in 32→64→96 per block).

5-fold cross-validation on training data; independent held-out test set (1/6 of data).

🔄 Evaluation Protocol

Dataset split 6-ways: 1 part fixed test set, remaining 5 used for 5-fold CV to tune hyperparameters. Final model retrained 5 times (one per training fold) on best params; CI/MSE averaged across 5 runs.

📏 Concordance Index (CI)

CI = (1/Z) Σ h(bᵢ − bⱼ) for all dᵢ > dⱼ

Measures whether predicted affinity values preserve the correct ranking order of true affinities. h(x) is the Heaviside step function. Z is a normalisation constant.

  • CI = 1.0 → perfect ordering
  • CI = 0.5 → random prediction
  • Higher is always better ↑

📉 Mean Squared Error (MSE)

MSE = (1/n) Σ (Pᵢ − Yᵢ)²

Standard regression loss. P = predictions, Y = true binding affinity values, n = number of samples. Used as both training loss and evaluation metric.

  • MSE = 0 → perfect predictions
  • Lower is always better ↓
  • Sensitive to large errors (squared term)

📐 r²ₘ Index

r²ₘ = r² × (1 − √|r² − r²₀|)

Modified r² for QSAR model validation. r²₀ is the squared correlation without intercept. Values > 0.5 on the test set indicate an acceptable QSAR model.

📈 AUPR

Area Under Precision-Recall Curve

For binary classification evaluation. Continuous affinity values binarised using thresholds: pKd ≥ 7 for Davis, KIBA score ≥ 12.1 for KIBA dataset.
